# Scrolling Text Animation

> A C program that displays a long text string scrolling horizontally in the console, simulating a marquee effect.

## Overview
This project is a **personal practice project** created to explore string manipulation and animation in C.  
It displays a predefined text message moving across the console from left to right in an infinite loop.

## Features / Functionality
- Scrolls a long string horizontally in the console  
- Uses custom functions for substring display and formatting  
- Demonstrates simple animation using loops and delays  

## Concepts / Skills Used
- Language: C  
- Programming Concepts: arrays, strings, loops, functions, console output  
- Timing simulation using busy waiting (for animation effect)  

## Folder / File Structure
- `scrolling-text-animation.c` → main source code  

## How to Run
1. Open `scrolling-text-animation.c` in a C compiler (e.g., Code::Blocks, DevC++, or GCC).  
2. Compile and run the program.  
3. The text will scroll continuously in the console (press Ctrl+C to stop).
