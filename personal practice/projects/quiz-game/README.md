# Quiz Game

> A menu-driven quiz game in C where the user can perform different operations based on input choices.

## Overview
This project is a **personal practice project** created to apply C programming concepts.  
The program allows the user to enter two numbers and perform one of the following operations:  
- Check even/odd  
- Check divisibility by 5  
- Compare which number is greater  
- Check if numbers are positive or negative

## Features / Functionality
- Menu-driven program for multiple operations  
- Uses conditional statements and ternary operators  
- Accepts user input for dynamic results  
- Outputs results clearly in the console

## Concepts / Skills Used
- Language: C  
- Programming Concepts: if-else, ternary operators, loops, user input/output  
- Console-based interaction  

## Folder / File Structure
- `quiz.c` → main source code  
- `questions.txt` → original assignment questions / prompts  

## How to Run
1. Open `quiz.c` in a C compiler (e.g., Code::Blocks, DevC++, or GCC).  
2. Compile and run the program.  
3. Follow on-screen menu prompts to perform the desired operation.
