# Hackathon Project (Semester 1)

This folder contains my **final submission for a single-day hackathon project** conducted as part of the Fundamentals of Programming course (Semester 1).

> Note: Due to time constraints, the project may still lack certain features, but this represents the final version submitted for the course.

## Project Overview
The project is designed to manage a **library system** where:
- Books can be tracked
- Issues are recorded
- Basic operations are implemented using C programming concepts

## Concepts Used
- File handling (reading/writing `.txt` files)
- Loops, conditions, and arrays
- Functions for modularity
- Basic data structures (arrays to store books and issues)

## Folder Contents
- `books.txt` → list of books in the library  
- `issue_books.txt` → records of issued books  
- `project.c` → main C source code  
- `project.exe` → compiled executable (optional, can remove from GitHub if `.exe` files are ignored)

## Key Notes
- This project was completed in a single day hackathon format  
- Functionality covers the core requirements only  
- Code is structured for clarity and learning purposes

---

### How to Run
1. Open the `project.c` in a C compiler (e.g., Code::Blocks, DevC++, or GCC).  
2. Compile and execute the program.  
3. Make sure `books.txt` and `issue_books.txt` are in the same folder as the executable.

This project demonstrates hands-on experience and understanding of **file handling, problem-solving, and practical C programming** within a tight deadline.
